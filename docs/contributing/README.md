# Contributing

Thank you for your interest in _pywebview_. It is maintained in free time and has no company behind it, so every contribution helps.

## Ways to contribute

- **Fix a bug.** Bug fixes are always welcome. See [Development](/contributing/development.md) for how to set up the project and submit a pull request.
- **Add a feature.** Open an issue first and discuss the feature with the maintainer. Pull requests with new features or public API are not merged without prior approval.
- **Report a bug.** Read [Bug reporting](/contributing/bug_reporting.md) before you open an issue.
- **Improve the documentation.** See [Documentation](/contributing/documentation.md).
- **Support the project financially.** See below.
